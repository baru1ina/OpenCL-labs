
# Курсовая работа по GPGPU: "Particle Game"

## Задание
- Поток частиц отражается/стекает от интерактивных предметов
- Предметы: сфера, куб, плоскость, две плоскости и тд
- Задача: сдвинуть предметы так, чтобы Х частиц попал в «корзину» за 15 сек. 
- Два типа частиц
  - Частицы одного типа не взаимодействуют друг с другом
  - Частицы разных типов отталкиваются абсолютно упруго

## Управление

### Камера

| Действие | Управление |
|----------|------------|
| Поворот камеры | ПКМ + движение мыши |
| Движение вперёд/назад | Колёсико мыши |
| Сброс камеры | `C` |

### Управление плоскостями

| Действие | Управление |
|----------|---------|
| Выбрать плоскость 1 | `1` |
| Выбрать плоскость 2 | `2` |
| Перемещение влево/вправо | `A` / `D` |
| Перемещение вверх/вниз | `Q` / `E` |
| Перемещение вперёд/назад | `W` / `S` |
| Наклон по оси X | `R` / `F` |
| Наклон по оси Z | `T` / `G` |

### Меню игры

| Действие | Управление |
|----------|---------|
| Пауза | `P` |
| Выход из игры | `Esc`/ Свернуть окно по крестику |
| Отладка камеры <br>(вывод положения в консоль) | `F1` |

## Условие завершения

Система содержит **20 000** частиц, которые постоянно переиспользуются. Частицы падают из эмиттера, взаимодействуют с плоскостями и попадают в корзину.

Необъоимо набрать 1200 очков (попаданий в корзину) за 15 секунд.

- Частица засчитывается, когда попадает в область корзины
- Одна частица = 1 очко
- После засчитывания частица возрождается в эмиттере
